所见即所得的 Markdown 编辑器

参考 Typora 编辑体验的桌面工具：输入即渲染、Mermaid 图表、脑图画布、多标签与主题切换， 基于 Vue 3 + Vditor，提供 Electron 与 Tauri 2 双运行方案。

Windows Vue 3 + Vite Vditor WYSIWYG Electron / Tauri 2 MIT

功能特性

为长期写作与文档阅读打磨的细节

✍️所见即所得编辑

Vditor WYSIWYG 模式，输入即所见，无需切换预览窗口。

🧩全类型源码可见

Mermaid / 图表 / 数学 / HTML 面板原地编辑源码，双击段落与表格精确编辑 Markdown。

📊Mermaid 与图表

流程图、时序图、甘特图离线渲染；代码块一键导出 PNG，表格导出图片 / Excel。

🧠脑图画布

Ctrl+M 插入模板，画布可视化编辑，支持导出 JSON / SVG / PNG。

🗂️多标签与文件树

标签切换 / 中键关闭 / 会话恢复；按文件夹浏览文档，当前文件自动定位。

🔎查找替换

Ctrl+F / Ctrl+H，大小写区分，逐个或全部替换。

🧰富文本浮动工具条

加粗 / 斜体 / 上下标 / 高亮 / 波浪线 / 颜色 / 字号字体，选区一键转 Markdown。

📤导出与打印

导出 HTML / Word / 整篇长图 / PDF（打印另存），代码块保留 ASCII 排版。

🔗链接智能分流

锚点文内跳转、外链开浏览器、本地 .md 应用内打开，悬浮显示地址与校验。

🖼️图片插入

拖入或粘贴图片，自动复制到文档旁 assets/ 并插入相对引用。

🌗主题与样式

浅色 / 深色全面适配即切；内容主题（Ant Design / WeChat 等）与自定义 CSS。

⚙️性能与监控

各进程内存 / CPU 实时折线图；可调 GPU 加速、渲染器堆上限等启动参数（Electron，重启生效）；支持自动保存与外部修改提示。

Web 版为浏览器演示（文档保存在本地浏览器存储，部分系统能力仅桌面版可用）

技术栈

渲染层 100% 共用，按需选择 Electron 或 Tauri 构建

Vue 3 Vite Vditor Electron Tauri 2 + WebView2 ECharts Lute Vitest
